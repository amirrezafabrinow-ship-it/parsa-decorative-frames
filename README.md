# قاب فروشی پارسا

قالب فروشگاهی فارسی و راست‌چین برای فروش قاب‌های دکوراتیو.

## اجرا
فایل `index.html` را در مرورگر باز کنید. برای بهترین تجربه، اتصال اینترنت جهت بارگذاری تصاویر و فونت لازم است.

## فایل‌ها
- `index.html`: ساختار صفحات و محتوا
- `style.css`: طراحی واکنش‌گرا و استایل‌ها
- `script.js`: فیلتر محصولات، جستجو و سبد خرید نمایشی

## نکته
این پروژه نسخه فرانت‌اند نمایشی است. برای فروش واقعی باید بک‌اند، مدیریت موجودی، ثبت سفارش و درگاه پرداخت اضافه شود.
